# Khomotso Video Studio

Site estático em HTML e CSS, sem dependências nem compilação.

## Publicar na Vercel

1. Extraia o ZIP.
2. Coloque `index.html`, `vercel.json` e `README.md` na raiz do repositório GitHub ligado ao projeto da Vercel. Não envie apenas o ZIP.
3. Confirme que o nome é exatamente `index.html`, sem números ou extensões adicionais.
4. Na Vercel, configure Framework Preset como Other, Root Directory como a raiz do repositório, Build Command vazio e Output Directory como `.`.
5. Guarde as alterações no GitHub e abra o deployment de produção concluído. Se necessário, use Redeploy na Vercel.

O README serve apenas de documentação; não é necessário para servir a página.
A configuração incluída não corrige um domínio ligado ao projeto errado ou um deployment inexistente.
